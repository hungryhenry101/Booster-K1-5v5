# 代码变更摘要 (未提交版本 vs. 最新提交版本)

本报告总结了当前未提交的更改与代码库中最新提交版本之间的差异（不包括文档文件）。

## 1. 大脑与策略 (src/brain)

### 新功能：RL 视觉踢球 (RL Visual Kick)
*   **实现：** 在 `brain_tree.cpp` 和 `brain_tree.h` 中实现了新的行为树节点 `RLVisionKick`。它管理基于机器学习的踢球策略，包括减速阶段、用于球追踪的头部扫描以及安全超时条件。
*   **消息传递：** 新增了 `/kick_ball` 话题（由 `brain.cpp` 发布），提供球位置、目标球门方向和计算出的踢球力量的实时信息，以支持视觉踢球系统。

### 行为树优化
*   **前锋表现 (Striker Play)：**
    *   将 `RLVisionKick` 集成到前锋的决策逻辑 (`StrikerDecide`) 中。
    *   更新了 `Chase` 和 `Adjust` 节点，调整了速度限制并引入了更精细的控制参数（如 `vtheta_factor`、`tangential_speed_far/near`），使接近球的过程更平滑。
    *   增加了 `Kick` 动作的稳定时间。
*   **定位与入场：**
    *   在 `game.xml` 的 `INITIAL` 和罚时状态中增加了 `SelfLocateEnterField` 和 `CamScanField`，确保机器人在开始比赛前已正确定位。
    *   增加了 `subtree_locate.xml` 中的允许距离和漂移阈值，以提高定位的鲁棒性。
*   **协作与定位：**
    *   `GoToFreekickPosition`：现在使用团队代价排名 (`tmMyCostRank`) 代替静态的前锋 ID，以便在自由球期间进行更好的动态角色分配。
    *   `Assist`：优化了定位逻辑，以处理机器人是场上唯一活跃球员的情况 (`rank == 0`)。
    *   `GoToReadyPosition`：简化并清理了拥挤回避逻辑。

### 核心逻辑更新
*   **参数处理：** 在 `brain.cpp` 中为自动视觉踢球增加了多个新的策略参数（如触发距离和角度）。
*   **稳定性：** `CheckAndStandUp` 现在会在机器人摔倒时明确发出信号，以中止任何正在进行的视觉踢球动作。

## 2. 视觉系统 (src/vision)

### 配置与标定
*   **相机参数：** 更新了 `vision.yaml` 中的相机内参和外参值。
*   **模型路径：** 将检测和分割模型的路径切换为相对路径。
*   **标定：** `calibration_node.cpp` 现在支持 `d-robotics` 相机的更新话题，并增加了将结果直接保存到 `/opt/booster/vision.yaml` 的提示。

### 视觉节点改进
*   **多相机支持：** 更新了话题名称和订阅逻辑，以更有效地支持 ZED、Orbbec 和 d-robotics 相机。
*   **性能监控：** 增加了检测结果发布间隔的日志记录，以监控视觉系统的延迟。
*   **代码清理：** 删除了冗余的调试打印，并简化了模型加载逻辑。

## 3. 脚本与环境

### 部署与构建
*   **构建脚本：** `scripts/build.sh` 现在使用标准的 `colcon build`，去掉了 `--symlink-install`。
*   **启动脚本：** `scripts/start.sh` 已更新，将 `vision_config_path` 指向 `/opt/booster`，并包含了用于 UDP 通信的特定 FastDDS 配置。
*   **设置脚本：** `set_up.py` 进行了易用性改进，例如增加了文件存在性检查和更好的用户反馈。
